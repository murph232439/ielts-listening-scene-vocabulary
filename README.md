# 雅思听力场景词汇训练站

基于《雅思听力场景词汇》整理的静态训练站，包含：

- 17 个场景，共 890 个词条
- 17 个课程补充场景，共 1653 个词条
- 学习入口：逐词听音、拼写检查和完整释义
- 听写入口：乱序出题、3 秒拼写、2 秒选择中文意思；只使用有原声的词条
- 错词库：自动收集错词，连续答对两次后移出
- 1244 个词条可播放原录音；音频按场景打包，每个词条使用独立切片数据，不依赖浏览器跳转时间点
- 其余词条保留音标、词性、释义、变形和例句
- 原录音未明确覆盖的 5 个词条不进行语音合成，播放按钮保持不可用
- 不播放中文释义发音

## 本地预览

```bash
python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。

## 数据来源

- 新东方在线雅思研发中心《雅思听力场景词汇》
- 用户提供的《雅思听力场景词汇录音（常速版）》
- 《听力场景词汇精华版》
- 《雅思听力场景词汇表汇总》
