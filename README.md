# 雅思听力场景词汇训练站

基于《雅思听力场景词汇》整理的静态训练站，包含：

- 17 个场景，共 890 个词条
- 17 个课程补充场景，共 1653 个词条
- 学习入口：逐词听音、拼写检查和完整释义
- 听写入口：乱序出题、15 秒拼写、10 秒选择中文意思；只使用有原声的词条
- 错词库：自动收集错词，连续答对两次后移出
- 2543 个词条统一使用在线英文神经语音
- 每个词条都保留音标、词性、释义、变形和例句
- 本地直接播放缓存音频，线上使用场景语音包
- 不播放中文释义发音

## 本地预览

```bash
python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。

## 数据来源

- 新东方在线雅思研发中心《雅思听力场景词汇》
- 用户提供的《雅思听力场景词汇录音（常速版）》
- 《听力场景词汇精华版》
- 《雅思听力场景词汇表汇总》
