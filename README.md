# 雅思听力场景词汇训练站

基于《雅思听力场景词汇》整理的静态训练站，包含：

- 17 个场景，共 890 个词条
- 学习入口：逐词听音、拼写检查和中文释义回听
- 听写入口：乱序出题、3 秒拼写、2 秒选择中文意思
- 错词库：自动收集错词，连续答对两次后移出
- 17 个场景使用原录音逐词时间轴，890 个词条中 885 个完成音频对齐
- 原录音未明确覆盖的 5 个词条不进行语音合成，播放按钮保持不可用
- 不播放中文释义发音

## 本地预览

```bash
python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。

## 数据来源

- 新东方在线雅思研发中心《雅思听力场景词汇》
- 用户提供的《雅思听力场景词汇录音（常速版）》
